# Safety Observer - PWA

Aplicación para registrar observaciones de seguridad en el trabajo.

## Funcionalidades
- Registro de observaciones (riesgos y buenas prácticas)
- Estadísticas y gráficas
- Mapas de calor
- Exportación a Excel y PDF
- Sincronización con Supabase

## Tecnologías
- HTML, CSS, JavaScript
- Chart.js para gráficas
- Supabase para base de datos
- PWA para uso offline
